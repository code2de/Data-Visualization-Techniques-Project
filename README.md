# Consumer Price Index (CPI) Analysis using CRISP-DM, SEMMA, and KDD

This repository contains the implementation of three popular data mining methodologies—CRISP-DM, SEMMA, and KDD—using the **All India Consumer Price Index (CPI) 2013–2023** dataset.

## Project Overview

The objective of this project is to compare the CRISP-DM, SEMMA, and KDD methodologies by applying them to India's Consumer Price Index dataset. The project includes data preprocessing, exploratory data analysis, visualization, and machine learning for CPI prediction.

## Dataset

- **Dataset:** All India Consumer Price Index (2013–2023)
- **Source:** Kaggle
